3 § Regeringen eller myndighet som regeringen bestämmer kan medge undantag från 1 §, om dumpning kan ske utan olägenhet från miljö skyddssynpunkt. Medgivande kan förenas med villkor.

Uppkommer genom dumpning olägenhet som ej förutsågs när medgivandet gavs, får den myndighet som lämnat medgivandet meddela föreskrift för att avhjälpa olägenheten.

Åsidosättes villkor eller föreskrift eller kan olägenhet som avses i andra stycket ej avhjälpas, får medgivandet återkallas. Lag (1975:735).
