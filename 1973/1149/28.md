28 § Förrättning som påbörjats enligt förordnande vid fastighetsreglering skall inställas, om regleringsförrättningen inställes. Förrä ttningen skall dock fortsättas, om sakägare som fört talan vid förrättningen och som kunnat ansöka om denna begär det.

Underrättas sakägarna om regleringsförrättning ens inställande vid sammanträde, skall begäran framställas vid sammanträdet. I annat fall skall begäran framställas inom tid som lantmäterimyndigheten föreskriver. Lag (1995:1405).
