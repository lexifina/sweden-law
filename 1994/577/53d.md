53 d § Minskningen enligt 53 c § av den del av bidragsbeloppet som kan krävas åter sker årligen, om inte länsstyrelsen beslutar att minskning ett visst år skall vägras. Om minskning vägras, kan den del av bidrags-beloppet som alltjämt kan krävas åter helt eller delvis omvandlas till ett lån med villkor som anges i beslutet.

Beslut att vägra minskning skall fattas senast tre månader efter det att länsstyrelsen fått kännedom om förhållanden som kan föranleda att minskning skall vägras. Förordning (1996:1571).
