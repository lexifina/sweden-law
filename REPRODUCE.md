# How this repository was made

Everything here is generated by the build scripts in `tools/build/` from a cache of the public sources. The same cache
gives the same commits, hash for hash.

## Sources (retrieved 2026-10-28)

- Riksdagen open data, document list: `https://data.riksdagen.se/dokumentlista/?doktyp=sfs&utformat=json&sz=200&p=N`
  (the API stops paging after 10,000 hits, so the list is completed by year: `&rm=YYYY`). 11,567 hits; the 11,433
  of subtype `sfst` are the statutes (133 nineteenth-century Riksdag regulations, OCR text, are left out).
- Riksdagen open data, each statute: `https://data.riksdagen.se/dokumentstatus/<dok_id>.json` (consolidated text as
  HTML and plain text, plus Utfärdad, Ändrad t.o.m., Upphävd and the repealing act).
- Regeringskansliets rättsdatabaser, the SFSR register: `https://rkrattsbaser.gov.se/sfsr?bet=<SFS number>`.
- Requests: 23892 over three fetch passes (the second and third retried transient failures; with `curl --compressed`, 4 at a time, User-Agent
  `Lexifina-law-archive/1.0`). robots.txt: data.riksdagen.se and rkrattsbaser.gov.se have none (HTTP 404);
  www.riksdagen.se, not fetched, names Claudebot, Claude-User and Claude-SearchBot only to set `crawl-delay:1`.
- Terms: Riksdagen's "Användningsvillkor" (open data free to use and redistribute with "Källa: Sveriges
  riksdag"; no use of the Riksdag's name or logo for the service). rkrattsbaser.gov.se publishes no terms page.
- Past versions: neither source keeps earlier consolidations (checked on 2026-10-28; Riksdagen has one document per
  statute, SFST shows the current text only), so this corpus is `history: current-only`.
- The sha256 of every cached response (decompressed) is in `data/source-sha256.tsv`.

## Commands, in order

```
python -X utf8 fetch.py          # list + per-statute JSON + SFSR (cache in .cache/, negative answers kept)
python -X utf8 build.py ../sweden-law --today 2026-10-28
python -X utf8 check_repo.py ../sweden-law
python scripts/global-law/check_corpus.py ../sweden-law
python scripts/test_corpus.py ../sweden-law tools/in_force_on.py
python -X utf8 build.py <other dir> --today 2026-10-28   # rebuild: same HEAD
```

## Decisions made by hand

- Current-only, as the sources keep no past consolidations; dated two-version provisions and repeals are the only
  in-record changes.
- A statute's main text is dated by the latest in-force day, not after the build day (or the day before its first dated
  change, or before its repeal), among the statute's own in-force day and every SFSR amendment up to the consolidation's
  "t.o.m." act (all dates in an Ikraft field count; the repealing act is left out).
- Statutes with two-version passages that do not split cleanly by date (markers on chapters or headings, or two
  versions in force on one day) are kept as printed and labelled `Text: as-printed`.
- Markers "den dag som regeringen bestämmer" (and other undated conditions) are never applied.
- Paragrafs without an anchor in the source are split where a stycke begins "<n> §".

## What AI did and did not do

The scripts were written by Claude Code with Claude Opus 5.5 (`claude-opus-5-5`), working for Lexifina. No AI wrote
or changed any legal text, and no model runs at build time or data time: the text is the publisher's, split by code.
